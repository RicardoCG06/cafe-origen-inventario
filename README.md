# Café Origen — Inventario Web

## Propósito del proyecto
Aplicación web desarrollada para visualizar el inventario de productos de **Café Origen** a partir de datos estructurados en formato JSON, resaltando automáticamente los artículos con existencias bajas (stock menor a 5 unidades).

## Tecnologías utilizadas
* HTML5
* CSS3
* JavaScript (Fetch API y manipulación del DOM)
* JSON

## Instrucciones de ejecución
1. Visita el enlace publicado en GitHub Pages, o bien clona este repositorio.
2. Si lo ejecutas de forma local, levanta un servidor estático (por ejemplo con `node server.js` o la extensión Live Server) para permitir la lectura de `inventario.json` mediante `fetch`.
